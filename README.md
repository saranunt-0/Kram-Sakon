# Kram Sakon — Storefront

Bilingual (Thai + English) luxury e-commerce storefront for a natural-indigo textile brand from Sakon Nakhon. Built with Next.js 16 (App Router), TypeScript, Tailwind v4, and next-intl.

> **This is a first-draft demo running on mock data** — no Shopify subscription, no payments, no real photography yet. It's for design review. See **[HANDOFF.md](./HANDOFF.md)** for the full developer handoff and the plan to go live on Shopify.

## Quick start

```bash
npm install
npm run dev      # http://localhost:3000  → /en or /th
```

Then explore `/en` and `/th`, the TH|EN and region switches, products, cart, and the cookie banner.
